# NXG Arms site update

This repo is only for getting files onto your computer. It is **not** the live Vercel repo.

## Clicks

1. On this GitHub page, click the green **Code** button.
2. Click **Download ZIP**.
3. Unzip the file.
4. Open **GitHub Desktop** → **nxg-arms** (JDC513).
5. Copy `src` (and any other folders here) **on top of** the nxg-arms folder. Choose Replace.
6. GitHub Desktop: **Commit to main** → **Push origin**.
7. Vercel will update itself.
